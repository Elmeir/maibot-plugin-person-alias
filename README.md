# 人物称呼与别名（maibot-plugin-person-alias）

> 两件事，全部通过插件 SDK 实现，不改宿主一行代码：**注入**——把「主称呼 + 别名」注入 Maisaka planner 上下文，让麦麦知道当前在说谁；**换名**——把运行时显示的 QQ 昵称/群名片替换成你维护的称呼，planner、回复器、日志、WebUI 看到的名字统一。

- 插件 ID：`github.elmeir.person-profile-name-alias`
- 宿主要求：MaiBot ≥ 1.2.4（maibot-plugin-sdk ≥ 2.0）
- 依赖：无
- 作者：[Elmeir](https://github.com/Elmeir) ｜ License：GPL-3.0-or-later
- 版本：见 [_manifest.json](_manifest.json) ｜ 变更见 [CHANGELOG.md](CHANGELOG.md)

## 功能

- **称呼注入**：向 planner 注入参考块，每行主语是 planner 在消息里实际看到的名字，后面列出这个人的其余全部叫法（档案主称呼、档案昵称、各群群名片、人工别名）：

  ```
  【人物称呼与别名-内部参考】
  豆包哥：别名=群豆包、包总
  ```

  只注入有增量的人物——没有其他叫法的不出现（注入了只是重复已知名字）。别名对照的价值在消息之外的名字来源：记忆/画像原文、知识库文本、换名前落库的历史消息里仍是原群名片，这是 LLM 把那些名字对上人的唯一渠道。
- **昵称替换**：与注入是两个独立开关，关闭注入后换名照常工作。

## 安装

```bash
cd /你的部署目录/plugins    # 例如 /opt/MaiBot/plugins
git clone https://github.com/Elmeir/maibot-plugin-person-alias.git
# 重启麦麦（systemctl restart xxx / docker compose restart / 重启 bot.py）
```

> 配置存在插件目录内的 `config.toml`，换目录名会丢配置；从旧目录名 `person_profile_name_alias` 升级的用户保持原名即可。

重启后到 WebUI 插件页找到「人物称呼与别名注入」并启用，配置项均有中文标题与说明（「生效范围」「名字来源」是下拉框）。

## 配置

### 换名（「昵称替换」配置段）

| 配置项 | 默认 | 说明 |
|---|---|---|
| 启用昵称替换 | 开 | 是否启用换名 |
| 生效范围 | 入站即改写 | `入站即改写`=改写消息体，planner/回复器/日志/WebUI 全链路生效；`仅改 planner`=只改 planner 请求文本，不碰消息体与数据库 |
| 名字来源 | 自动 | `自动`=主称呼优先，无则用第一个人工别名；`仅主称呼`；`仅人工别名` |
| 替换 QQ 昵称 | 开 | 仅「入站即改写」范围有效 |
| 替换群名片 | 开 | 群聊显示名以群名片优先，关掉可能导致替换看不到效果 |
| 替换 @ 与引用对象 | 开 | 同时替换 @ 与引用里被指向人的昵称 |
| 改写正文里的 @旧名 | 开 | 改写正文里的 `@旧名`、`回复了旧名的消息` 两类固定格式 |
| 硬编码覆盖（JSON） | 空 | 形如 `{"qq:123456789": "老王"}`，优先级最高（没进人物档案也能用） |

名字来源优先级：`overrides` → 人物主档案 `person_name` → A_Memorix 人工别名；旧版本配置取值读取时自动迁移，无需手动改。只有进了人物档案（`is_known=True`）的人才会被替换，陌生人保持原样（用 `overrides` 指定）。

### 注入（「注入」配置段）

| 配置项 | 默认 | 说明 |
|---|---|---|
| 启用注入 | 开 | 是否向 planner 注入人物参考块；关闭后换名照常工作 |
| 每轮最多注入人数 | 3 | 按最近发言顺序取前几位 |
| 注入别名 | 开 | 注入"叫法对照表"；关闭后注入块整体停用 |
| 候选保留时长 | 300 秒 | 超时没有被提到的人物不再注入 |
| 会话不匹配时回退 | 开 | 会话 ID 对不上时回退用最近 45 秒内记录的人物 |

## 使用

- 想「运行时看到的就是新名字」→ `入站即改写`（默认）。代价：替换后的名字会写入消息记录，新认识的人可能把新名记进档案的群名片列表。
- 只让 planner 看到新名字、不碰数据库 → `仅改 planner`。代价：WebUI 监控面板、日志里仍是原昵称。

## 身份认定

一律用 `platform + user_id`（QQ 号）解析人物身份，拿不到 QQ 号就保持原样、绝不按名字猜人——群名片可被本人随意修改，按名字精确匹配会认错对象。别名列表里包含群名片，但只描述"这个人有哪些叫法"，不参与身份判定。
